## Aturan umum untuk penamaan variabel adalah:

- Nama dapat berisi huruf, angka, dan garis bawah.
- Nama harus diawali dengan huruf atau garis bawah (_)
- Nama bersifat peka huruf besar-kecil ( myVardan myvarmerupakan variabel yang berbeda)
- Nama tidak boleh mengandung spasi atau karakter khusus seperti !, #, %, dll.
- Kata-kata yang dicadangkan (seperti int) tidak dapat digunakan sebagai nama.


## Data Type

- int |	2 or 4 bytes | Stores whole numbers, without decimals | 1

- float | 4 bytes | Stores fractional numbers, containing one or more decimals. Sufficient for storing 6-7 decimal digits | 1.99

- double | 8 bytes	Stores fractional numbers, containing one or more decimals. Sufficient for storing 15 decimal  digits | 1.99

- char | 1 byte | Stores a single character/letter/number, or ASCII values | 'A'


## ngilangin 0 atau bilangan tambahan setelah titik di float atau double 

Jika Anda ingin menghilangkan angka nol tambahan (mengatur presisi desimal), Anda dapat menggunakan titik ( .) diikuti dengan angka yang menentukan berapa banyak digit yang harus ditampilkan setelah titik desimal:

Contoh
float myFloatNum = 3.5;

printf("%f\n", myFloatNum);   // Default will show 6 digits after the decimal point
printf("%.1f\n", myFloatNum); // Only show 1 digit
printf("%.2f\n", myFloatNum); // Only show 2 digits
printf("%.4f", myFloatNum);   // Only show 4 digits


## Mengapa Saya Perlu Mengetahui Ukuran Tipe Data?

- Mengetahui ukuran tipe data membantu Anda memahami berapa banyak memori yang digunakan program Anda. Hal ini penting saat menulis program yang lebih besar atau bekerja dengan memori terbatas, karena dapat memengaruhi kinerja dan efisiensi.

- Sebagai contoh, ukuran suatu chartipe data adalah 1 byte. Artinya, jika Anda memiliki array berisi 1000 charnilai, maka array tersebut akan menempati memori sebesar 1000 byte (1 KB).

Menggunakan tipe data yang tepat untuk tujuan yang tepat akan menghemat memori dan meningkatkan kinerja program Anda.
